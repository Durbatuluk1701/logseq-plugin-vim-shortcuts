## 2025-02-14 - XSS in Vue v-html and raw DOM manipulations
**Vulnerability:** XSS via `v-html` in `Command.vue`, `CopyText.vue`, `Mark.vue` and manual `innerHTML` concatenations for string highlights in `search.ts` and `funcs.ts`.
**Learning:** `innerHTML` and `v-html` were commonly used to inject small pieces of data (descriptions, copied text) where text binding (`{{ }}`) was perfectly sufficient. For highlights, string concatenation and RegExp was being done on `innerHTML`, which leads to code execution vulnerabilities. Furthermore, a simple markdown renderer did not escape html attributes quotes or protocol (`javascript:`) in image and link URLs.
**Prevention:** Always use `v-text` or `{{ }}` for inserting non-HTML strings. When manual highlight modifications are required, either use safe DOM APIs (e.g. `querySelectorAll`, `replaceChild`, `createTextNode`) or carefully escape HTML entities (`<`, `>`, `&`, `'`, `"`) before string concatenation and injection. Filter `javascript:` URIs when parsing markdown links and images.
